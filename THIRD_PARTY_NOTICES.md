## Data and tile services (not bundled; requested at runtime)

- Base map: OpenStreetMap tiles, © OpenStreetMap contributors (ODbL), subject to the OSM Tile Usage Policy.
- Traffic: TomTom Traffic raster tiles (your own API key, TomTom terms apply).
- Earthquakes: U.S. Geological Survey (USGS) Earthquake Hazards Program real-time GeoJSON feeds (US government data, public domain; courtesy of USGS).
- Radar: NOAA nowCOAST (US government, public domain), Iowa Environmental Mesonet NEXRAD composites, RainViewer public API (attribution required).
